# Цып-Цып — новая версия

## Загрузка в GitHub Pages
1. В репозитории откройте **Add file → Upload files**.
2. Загрузите `index.html` из этой папки.
3. Commit changes в `main`.
4. Откройте **Settings → Pages**.
5. Source: **Deploy from a branch** → Branch `main` → Folder `/(root)` → Save.

Игра сделана одним HTML-файлом, поэтому отдельные папки assets для этой версии не нужны.
